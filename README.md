# 케이크 합치기

브라우저에서 바로 하는 무한 모드 케이크 합치기 퍼즐. `index.html` 하나로 동작합니다.

- 4×5 테이블에 쟁반의 접시 3개를 끌어다 놓거나, 탭해서 고른 뒤 빈칸을 탭해 놓습니다.
- 같은 케이크가 위·아래·옆으로 이어지면 조각이 가장 많이 찬 접시로 모입니다. 6조각이 모이면 완성되어 사라집니다.
- 접시에는 항상 한 종류의 케이크만 올라갑니다(1~3조각, 설정에서 "1조각 접시만" 선택 가능).
- 새 접시는 지금 테이블 상태를 보고 만들어집니다. 빈칸 옆에 있는 케이크 무리에 부족한 조각 수를 채워 주는 접시가 나오고, 테이블이 찰수록 그런 접시가 더 자주 나옵니다.
- 케이크를 6판 완성할 때마다 새 케이크 종류가 추가됩니다(최대 8종). 10판마다 "접시 바꾸기"가 1회 늘어납니다.
- 진행 상황과 최고 점수는 브라우저에 저장됩니다.
