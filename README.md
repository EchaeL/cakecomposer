# 놀이 상자

브라우저에서 바로 하는 미니게임 모음. `index.html`(홈)에서 게임을 골라 들어갑니다.

```
index.html            홈 화면 (게임 목록)
games/cake/index.html   케이크 합치기
games/tetris/index.html 테트리스
```

새 게임을 추가하려면 `games/<이름>/index.html`을 만들고, `index.html`의 `GAMES` 목록에 항목을 하나 추가하면 됩니다.

## 케이크 합치기

무한 모드 케이크 합치기 퍼즐.

- 쟁반의 접시 3개 중 하나를 테이블 빈칸에 끌어다 놓거나, 탭해서 고른 뒤 빈칸을 탭해 놓습니다. 쓴 자리는 바로 새 접시로 채워집니다.
- 접시 하나에는 최대 6조각, 케이크 종류는 최대 3가지까지 올라갑니다.
- 위·아래·옆으로 붙은 접시끼리 같은 케이크 조각이 그 케이크를 더 많이 가진 접시(자리가 남은 접시)로 모입니다. 바뀐 접시는 다시 검사해서 연쇄로 합쳐집니다.
- 한 접시가 같은 케이크 6조각으로 채워지면 완성되어 사라지고, 비워진 접시도 치워집니다.
- 새 접시는 지금 테이블 상태를 보고 만들어집니다. 빈칸 주변 케이크와 맞물리는 접시가 나오고, 테이블이 찰수록 그런 접시가 더 자주 나옵니다.
- 케이크를 8판 완성할 때마다 테이블이 아래로 한 줄, 옆으로 한 칸씩 번갈아 끝없이 늘어납니다.
- −/+ 버튼, "전체" 버튼, 두 손가락 핀치(또는 Ctrl+휠)로 보기 크기를 바꿔 한 화면에 더 많은 접시를 볼 수 있습니다. 6판마다 새 케이크 종류가 추가됩니다(최대 8종).
- 진행 상황과 최고 점수는 브라우저에 저장됩니다.

## 테트리스

- 7가지 블록을 한 묶음씩 섞어 내보내는 방식(7-bag), SRS 회전과 벽 차기, 고스트 블록.
- 홀드: 지금 블록을 보관하고 보관한 블록을 꺼냅니다. 블록 하나가 떨어질 때까지 한 번만 쓸 수 있습니다.
- 다음 블록 3개 미리보기.
- 점수: 1/2/3/4줄 100/300/500/800 × 레벨, T-스핀, 테트리스·T-스핀 연속 보너스(×1.5), 콤보, 퍼펙트 클리어. 10줄마다 레벨이 올라 빨라집니다.
- 키보드: ←→ 이동, ↓ 천천히, Space 바로 내리기, ↑/X 회전, Z 반대 회전, C/Shift 홀드, P 멈춤.
- 터치: 아래 버튼, 또는 판 위에서 좌우로 밀어 이동, 톡 쳐서 회전(왼쪽 가장자리는 반대 회전), 아래로 휙 쓸어 바로 내리기, 위로 쓸어 홀드.
